## BIXI Availability Prediction

![BIXI availability prediction concept — current versus future bike and dock availability]({{ '/assets/bixi_availability_now_versus_next.png' | relative_url }})

*Concept visualization illustrating how predictive availability could improve BIXI trip planning. The interface shown is a proposed feature, not a deployed application.*


**Machine Learning · Time-Series Forecasting · Montréal**

An applied machine learning project addressing the
difficulty of finding available bicycles and empty
docks at bike-sharing stations.

The work investigates predicting station availability
over 15-, 30-, and 45-minute horizons using historical
trip and station data.

**Technologies:** Python, Pandas, CatBoost,
Data Analysis, Predictive Modeling.

## ReturnERA

**Product Engineering · Full-Stack Development · Cloud**

A parcel-return pickup service designed to make online
shopping returns more convenient.

Developed an online booking platform with backend APIs,
relational database models, payment integration, and
cloud deployment workflows.

**Technologies:** Next.js, React, TypeScript,
PostgreSQL, Prisma, Stripe, AWS Lightsail, Docker.
